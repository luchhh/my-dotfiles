---
name: daily-digest
description: What's up on work
argument-hint: filter date, defaults to last workable day
---

Interpret $ARGUMENTS to get a filter date, if no arguments is passed, assumed the filter date is the last workable day

Use the following commands to generate my daily digest

- /dev-news
- /slack-summary {filter_date}
- /obsidian-summary
- Use list_my_issues from linear to make a list of my pending issues
